# QA-портфолио: автотесты на Python

## Проверка постов для соцсетей
Функция `check_post` проверяет текст поста перед публикацией:
- нет точки в конце абзаца (многоточие разрешено);
- длина не больше 2200 символов (лимит подписи Instagram);
- нет запрещённых фраз («пишите в телеграм», «ссылка в профиле»).

## Как запустить тесты
```
pip install pytest
pytest -v
```

## Что применено
- TDD: сначала падающий тест, потом код
- анализ граничных значений (2200 / 2201)
- негативные проверки
- параметризация тестов (`pytest.mark.parametrize`)
